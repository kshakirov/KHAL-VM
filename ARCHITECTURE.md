# Архитектура Graph KHAL

Программа представлена графом. Узлы фиксированного размера хранятся в
арене `std::vector<Node>`. `NodeId` — 32-битный знаковый индекс;
`no_node` обозначает отсутствующую ссылку.

Узел хранит неизменный `id`, тег, связи `left/right`, слово `data` и
маршрутные поля `back/is_right`. У `APP` левое ребро ведёт к функции,
правое — к аргументу. У `INT` число находится в `data`.
`I`, `K` и `S` различаются тегами; редукция реализована только для `I`.

Курсор хранит ID текущего узла. `reduce` начинает с переданного положения,
спускается влево по `APP` и записывает временные обратные ссылки `back`.
Это след обхода, а не постоянные родители узлов.

У `I` курсор возвращается к ближайшему `APP` и берёт его правый аргумент.
Для корневого редекса курсор получает ID аргумента, и автомат останавливается.
Для вложенного редекса результат записывается в левое ребро внешнего `APP`.
В этюде `((I 42) 54)` это даёт `(42 54)`.

Цикл прототипа ограничен пятью итерациями. Вложенный этюд заканчивается
по этому лимиту; общей проверки завершённости вычисления пока нет.
