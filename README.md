zd# KHAL-VM (Kirill + HAL Virtual Machine)

Исследовательская функциональная виртуальная машина с регистровой архитектурой и однопроходным Лисп-фронтендом. Проект создается итеративно, мелкими шагами, на стыке низкоуровневого системного программирования и теории функциональных языков.

---

## 🧭 СТРАТЕГИЯ РАЗВЕРТЫВАНИЯ БОРТА

1. **Этап 1 (Sandbox):** Проектирование физики ядра, системы команд (ISA) и синтаксиса в интерактивной среде Emacs. Прототипирование на скриптовых движках без инфраструктурного шума (`F#` / `Chez Scheme`).
2. **Этап 2 (Перенос на Металл):** Полный перенос проверенной логики на **чистый C++** по заветам **Бьёрна Страуструпа** (контроль ресурсов через RAII) и **Александра Степанова** (математическая строгость, обобщенные алгоритмы).

# KHAL-VM

## ⚖️ АРХИТЕКТУРНЫЙ СДВИГ: ПОЛНЫЙ ПЕРЕХОД НА C++

Мы полностью отказались от управляемых платформ (.NET / F#) из-за скрытого оверхеда рантайма, навязанной иммутабельности и отсутствия прямого контроля над физикой железа. 

Проект KHAL-VM переходит на **чистый нативный ISO C++20** по заветам **Бьёрна Страуструпа** (RAII, детерминизм памяти) и **Александра Степанова** (математическая строгость алгоритмов).

### Новый план каталогов репозитория:
* `/khal_vm_cpp` — Исходный код нативного вычислительного ядра (C++).
* `/doc` — Суровый технический журнал проекта (`journal.tex`).
## 📁 НАЦИОНАЛЬНАЯ C++ ВЕРФЬ (ФАЙЛОВАЯ СТРУКТУРА СKЕЛЕТА)

Мы развернули олдскульную Unix-сетку компонентов в директории `khal_vm_cpp/src/`. Каждый файл имеет строгое функциональное назначение:

1. `main.C` — Главный процесс ВМ. Ловит входную строку из REPL, проверяет аргументы и запускает логгер.
2. `frontend.hpp` — Интерфейс компилятора. Объявляет функцию `compile`.
3. `frontend.C` — Реализация компилятора. Переводит текст в плоский вектор байт-кода.
4. `vm.hpp` — Интерфейс вычислительного ядра. Объявляет структуру ВМ (`Register registers[256]`, стек).
5. `vm.C` — Реализация ядра. Содержит главный цикл исполнения инструкций.
