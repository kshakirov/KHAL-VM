# Graph KHAL

Graph KHAL — исследовательская машина для вычисления через локальное
переписывание графа применений. Отправная точка — комбинаторная логика SKI.
Проверяем модель исполняемыми этюдами.

```sh
make test
```

Исходники машины — в `include/` и `src/`, исполняемые этюды — в
`studies/`. Устройство текущей реализации описано в
[ARCHITECTURE.md](ARCHITECTURE.md). Открытые вопросы ведём в
[Issues](https://github.com/kshakirov/KHAL-VM/issues).
