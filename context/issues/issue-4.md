## Описание

## Назначение

Сделать минимальный текстовый ассемблер KHAL для исследовательских программ VM.

Это не parser JavaScript и не полноценный frontend. Его задача — убрать ручное создание десятков C++-переменных `Instruction` и дать читаемый стенд вида:

```text
FUNCTION_START
LOAD_INT 100
LOAD_INT 200
ADD_INT
RETURN
FUNCTION_END
CALL
PRINT_INT
```

## Первый контракт

```text
одна строка → один opcode + список числовых операндов
программа   → vector<Instruction>
```

## Ближайшие задачи

- [ ] распознавать все текущие opcode;
- [ ] поддержать команды как с параметрами, так и без них;
- [ ] преобразовывать числовые параметры;
- [ ] собирать инструкции в `vector<Instruction>`;
- [ ] подключить результат к существующему frontend/VM;
- [ ] явно реагировать на `UNKNOWN`;
- [ ] сохранить простой отдельный запуск parser для отладки.

## Граница

Пока не вводить AST, выражения JavaScript, идентификаторы, объекты и сложную грамматику. Этот инструмент нужен только для ясной проверки семантики KHAL.

### kshakirov — 2026-10-01T20:52:25Z

Сегодня я поднял первый самостоятельный проход мини-ассемблера.

Что уже работает:

- появилась отдельная цель `make parser` с явными зависимостями от `parser.C` и общего заголовка;
- программа разбивается на строки без захвата предыдущего перевода строки;
- `LOAD_INT 222` и `LOAD_INT 333` распознаются;
- числовая часть преобразуется через `stoi` и записывается в operands;
- результат `parse()` уже добавляется в `vector<Instruction>`;
- парсер можно собирать и запускать отдельно от основной VM.

Текущая граница опыта видна хорошо: распознавание opcode пока начинается только при встрече пробела. Поэтому команды без параметров — `ADD_INT`, `PRINT_INT`, `FUNCTION_START`, `FUNCTION_END`, `CALL`, `RETURN` — остаются `UNKNOWN`.

Мой ближайший шаг: сначала выделять имя opcode целиком через позицию первого пробела, причём при отсутствии пробела считать opcode всей строкой. После этого отдельно разбирать параметры. Пока не подключаю настоящий язык, AST или JavaScript-синтаксис: нам нужен маленький надёжный KHAL-assembler как стенд для `CALL/RETURN`.
