# Graph Traversal

Автомат спускается по левым рёбрам `APP`, записывая временные `back`.
Достигнув `I`, возвращается по `back` к ближайшему применению.
`back` — след прохода, не постоянная связь с родителем.

Для вложенного этюда показан один редукционный проход. Текущий прототип
ограничен пятью итерациями; общей стратегии остановки он не реализует.
