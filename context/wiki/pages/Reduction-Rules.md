# Reduction Rules

Реализовано правило `I x → x`: результат — правый аргумент ближайшего
`APP`. Для корневого применения меняется точка входа; для вложенного
применения на левой цепочке переписывается левое ребро родителя.

Этюд `((I 42) 54) → (42 54)` проверяет, что внешний `APP` сохраняется,
его левое ребро теперь ведёт на `42`, а правое по-прежнему на `54`.
