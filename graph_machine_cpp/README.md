# Graph Machine

Минимальный экспериментальный C++-контур графовой машины.

Он размещён отдельно от регистровой реализации `khal_vm_cpp`, чтобы две
вычислительные модели не делили типы и предположения до установления их
действительной связи.

## Структура

- `include/graph_machine.hpp` — данные и объявления свободных функций;
- `src/graph_machine.C` — арена и перемещение курсора;
- `src/main.C` — проверка графа `APP(APP(ADD, 1), 2)`.

Сборка и проверка:

```sh
make test
```

Правила редукции пока отсутствуют.
